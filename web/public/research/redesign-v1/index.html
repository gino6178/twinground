What changed

160 of 163 source CTX images contributed crops to multiple original dataset splits. We regrouped entire sources and nearby nominal source centers before training. The new split has 8,115 training, 2,747 validation and 5,288 test images. All 15 classes are retained.

Nearby sources are grouped using 350 km connected components on Mars. Coordinates are approximated from CTX IDs; exact crop footprint separation is not verified. The 52 test sources form 13 spatial groups.

Uncertainty and deployment gate

CNN + supervised contrastive learning: paired spatial-group bootstrap difference versus texture baseline, 95% interval [0.006, 0.079]. This is a relative baseline comparison, not operational readiness.

CNN / cross-entropy only: paired spatial-group bootstrap difference versus texture baseline, 95% interval [-0.044, 0.064]. This is a relative baseline comparison, not operational readiness.

Loss ablation remains inconclusive: contrastive minus CE-only macro-F1 is +0.050; the paired spatial-group bootstrap 95% interval is [-0.016, 0.087], crossing zero. A higher point estimate alone does not establish the benefit of the contrastive objective.

Limits

  • Mars-only image-level geomorphology, not pixel segmentation or material labels
  • 350km nominal grouping reduces related-source leakage but exact source/crop footprint separation remains unverified
  • No Earth analogy or field suitability truth in this dataset
  • Some classes have very uneven source-group support; inspect every class.
  • This test has now been evaluated for both preregistered runs. Further tuned experiments must not call it untouched.
  • No human ratings were collected; image-class labels are supplied by the dataset authors.
  • Contrastive loss ablation is not a multimodal DEM/imagery/geology ablation.
