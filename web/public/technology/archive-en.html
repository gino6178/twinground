01 / SEARCH WORKFLOW

Read one search from start to finish

Elevation drives shape retrieval. Selected environment and lithology conditions also affect eligibility and ranking.

Choose a region

Select a named place or coordinates and a 20, 40 or 80 km square. The query samples elevation in meters; imagery helps locate and interpret the region.

Encode shape and relief

Subtract the median elevation and scale by robust relief. A separate relief input retains information about the original vertical scale.

Locate and compare

Inspect Earth red points, paired terrain views and evidence. Five spatial groups appear first; load more from the shortlist. Save candidates and compare up to three snapshots.

03 / EQUATIONS & CODE

What each number means

H is the 32 × 32 elevation grid. P₉₀ and P₁₀ are its 90th and 10th percentiles. Clipping bounds extreme inputs.

Relative height

Remove absolute altitude and normalize shape. The encoder floors relief at 1 m; the displayed relief is the original percentile difference.

lunar_pipeline.py → model_input()
R = max(P₉₀(H) − P₁₀(H), 1)
h = clip((H − median(H)) / R, −3, 3)
Example: relief 800 m, median 500 m, cell 700 m → h = 0.25.

Height-change channel

Finite differences highlight edges and elevation variation. This grid-gradient feature is not physical slope in degrees.

model_input() → np.gradient(height)
g = clip(√(gₓ² + gᵧ²) × N / 4, 0, 3)
X = stack(h, g), N = 32
Input: 2 × 32 × 32.

Shape plus original relief

The convolutional features and log relief form a unit embedding. Relief is supplied as a numeric value in meters.

TinyTerrainEncoder.forward()
r = (ln(1 + R) − ln(501)) / 5
u = MLP([CNN(X), r])
z = u / max(‖u‖₂, ε)
MLP: 25 → 32 → 24. ε protects normalization.

Similarity and context

Unit vectors q and e give cosine similarity q · e. When conditions are enabled, each needs at least six supported points among nine regional samples. With no conditions, ranking uses terrain alone.

web_server.py / context_ranker.py
S = 0.65 × (q · e + 1) / 2 + 0.35 × mean(C)
C contains support fractions for enabled conditions. Fixed weights and a 60% threshold are design choices, not a trained material classifier or calibrated probabilities.

The shortlist contains at most 512 eligible windows. Spatial grouping uses a separation of 1.5 times the window width; neighboring windows remain inspectable. The shortlist is not an exhaustive list of all Earth locations.

Training objective of the terrain encoder

Rotations by multiples of 90°, reflections and small noise create two views of a window. Contrastive learning brings paired views together relative to other batch views.

ℒᵢ = −ln[exp(zᵢ · zⱼ / τ) / Σₖ≠ᵢ exp(zᵢ · zₖ / τ)]

τ = 0.16; see train_tiny_lunar_encoder.py → contrastive_loss(). This is a same-window objective, not independent cross-planet analogy labels or a guarantee of rotation invariance.

Input size is not source resolution

Resampling a coarse DEM to 32 × 32 for inference or 64 × 64 for display does not create finer measured detail.

Why elevation first?

Illumination, color and viewing conditions vary across imagery. The deployed encoder compares elevation shape; displayed textures are not material predictions.

Coverage is finite

The prepared index has 500,385 windows: 337,384 at 20 km, 81,138 at 40 km and 81,863 at 80 km. Sampling density and available data vary; this does not imply complete geographic coverage.

06 / RESEARCH — NOT DEPLOYED

Two experiments toward richer evidence

These models have not replaced the production ranking. No human or expert scoring is part of the revised plan.

Reliability audit: confidence rejection failed

Validation-only temperature scaling improved test ECE from 0.1564 to 0.0303, but the frozen threshold retained only 14.15% of test images with 17.11% error. All 64 synthetic-noise inputs passed. The consumed test and reused validation splits make this a post-hoc audit; it does not validate unknown rejection.

Full audit, reliability chart, frozen threshold and failure cases ↗

Mars image classification: DoMars16k

Public geomorphology labels cover 16,150 images and 15 classes. CTX source identities and approximate source-center groups define the split, including 5,288 test images. Source centers are not exact crop footprints.

CNN with a contrastive term achieved macro-F1 0.420 versus 0.374 for the texture baseline. Two classes had F1 zero. The confidence interval for removing the contrastive term crosses zero, so its additional benefit is not established. This Mars-only image task does not validate Earth materials or cross-planet relevance.

Image–DEM correspondence: recover the same window

16,939 approximately 200 m windows come from 15 existing sources. Valid masks and a common grid pair images with elevation. Fourteen geographic source groups define the split; 225 Jezero windows are a single-site external probe. All sites had already been used by this project.

Paired-model equations and evaluation

Per-window preprocessing

Compute μ and σ over valid pixels. Mask m retains missing locations. No cross-sensor radiometric calibration is claimed.

train_paired_correspondence.py → preprocess()
x = m × clip((a − μ) / max(σ, 1), −5, 5)Input: stack(x, m).

Symmetric contrastive learning

64 same-source windows per batch, τ = 0.1. Other identities are contrastive negatives, not evidence of dissimilar geology or mission relevance.

train_paired_correspondence.py → run()
ℓᴵ→ᴰᵢ = −ln[exp(zᴵᵢ · zᴰᵢ / τ) / Σⱼ exp(zᴵᵢ · zᴰⱼ / τ)]
ℒ = (mean(ℓᴵ→ᴰ) + mean(ℓᴰ→ᴵ)) / 2

07 / VERIFICATION & OPEN WORK

Trace a result, and keep its limits visible

Query exports preserve coordinates, window size, source references and model/index hashes. The Markdown report follows the selected language; JSON, GeoJSON and CSV preserve the underlying data. Saved comparisons are browser-local snapshots, not a shared scientific database.

The interface supports 2D DEM fallback when WebGL is unavailable or lost. Red-point selection remains usable. These elevation maps are not satellite-image overlays. A separate expandable 2D image pair provides linked zoom and pan for Moon/Earth imagery, with attribution and explicit missing-image states. Local Jezero and Olympus USGS CTX orthophotos are connected where the query overlaps valid source pixels. Transparent checkerboard areas remain missing; coverage is the finite projected display-pixel fraction. Source grid spacing, license and hashes are shown. Acquisition dates and physical registration residuals are not independently verified. Earth exports are resampled from the actual service extent; this is not physical registration validation. Browser storage failures report that saving did not succeed and preserve existing data.

Training, inference, builds and automated tests run on the project server. Published evidence includes baselines, ablations and failure cases. AI assistance was used in implementation and documentation; generated explanations do not replace source measurements or independent scientific validation.

Remaining gates include fine-scale Earth labels compatible with the Mars task, independent cross-planet relevance labels, image-registration residual checks, DEM/image/geology fusion, a validated purpose ranker and calibrated missing-data/OOD behavior. Full licensing, reproducibility and competition-delivery audits are still in progress.

Earlier local microterrain and material experiments

Earlier experiments include limited high-resolution lunar/Mars reference crops and eight small Earth research regions, geomorphon and TinyMorphEncoder retrieval, and a small mineral-spectra pilot. They are not the production wide-area encoder described above. Their same-window or development-set results do not validate global analog relevance.
